# portfolio-risk-engine-go

本地组合风险计量与压力测试引擎：基于本地行情与持仓数据，提供历史模拟与参数法两种口径的 VaR / ES 计量，支持行情增量更新、并发重算与压力情景叠加。

## 模块结构

| 包 | 职责 |
|---|---|
| `market` | 行情类型、线程安全行情库（`Store`）、行情校验与拒绝原因 |
| `portfolio` | 持仓定义、市值估值、权重归一化 |
| `risk` | VaR/ES 计量（历史模拟、参数法）、风险引擎（`Engine`）、压力情景 |

## 风险模型口径

### 权重与暴露归一化
- 暴露 = 持仓数量 × 最新价格；多头为正、空头为负，方向不丢失。
- 权重按**净市值**归一（权重和为 1）；完全对冲（净市值为 0）时退化为按**总绝对暴露**归一，避免除零。
- 任何持仓标的缺价即返回 `MissingQuoteError`，不静默跳过、不按零计价。

### 历史模拟法（`historical`）
- 组合历史损益序列：`pnl[t] = Σ_s weight[s] × return[s][t] × 组合市值`。
- 损失序列升序排序，VaR 取**最近秩分位**（`k = ceil(c·n)`，无插值歧义）；ES 为不小于 VaR 的损失均值。
- 同一输入结果完全可复现（排序与秩选择均为确定性）。

### 参数法（`parametric`，方差-协方差）
- 假设组合损益正态：`VaR = -(μ - z_c·σ)`，`ES = -(μ - σ·φ(z_c)/(1-c))`。
- 正态逆 CDF 采用 Acklam 有理逼近 + 一步 Halley 精化，确定性实现；标准差计算先排序再累加，稳定浮点求和顺序。

### 压力情景（`stress`）
- 情景定义为 `symbol → 相对冲击`（如 `-0.2` 表示跌 20%）。
- 口径：情景产生一次性损益 `shockPnL = Σ 暴露 × 冲击`，**叠加**到当前组合的历史损益分布上（分布整体平移），再取历史模拟分位。这样冲击不会被归一化权重"洗掉"。
- 情景只作用于本次计算，**不写回行情库**；压力后基础重算结果不变（有测试保证）。
- 情景引用未持有的标的即报错。

## 并发与数据更新的一致性规则

1. **快照隔离**：`Compute`/`Stress` 先取行情库快照（`Store.Snapshot` 返回拷贝），整个计量过程只读快照与不可变的收益历史，多个组合并发重算无数据竞争、无结果串扰（`-race` 验证）。
2. **增量即全量**：引擎不在内存中维护增量中间态，每次计量都从当前行情状态全量推导，因此"逐条增量更新后重算"与"一次性全量装载后重算"结论在容差（1e-9，实际为 0）内一致。
3. **序号防重防乱**：每条行情携带单调递增 `Seq`：
   - `Seq == 当前` → `DUPLICATE_SEQ`，幂等忽略，不重复计价；
   - `Seq < 当前` → `OUT_OF_ORDER`，拒绝；
   - 被拒绝的更新不改变已有状态，结论不漂移。
4. **估值时刻**：取快照中最新行情时间作为估值参考时刻，各标的行情相对该时刻做时效校验。

## 异常行情处理策略

所有异常均以 `*market.RejectError` 返回，`Reason` 字段可区分，绝不静默跳过或按零处理：

| 原因 | 触发条件 | 行为 |
|---|---|---|
| `INVALID_PRICE` | 价格 ≤ 0、NaN、±Inf 或空标的 | 写入时拒绝 |
| `MISSING_QUOTE` | 持仓标的无行情 | 计量时失败 |
| `STALE_QUOTE` | 行情时间距估值时刻超过 `maxStaleness` | 计量时失败（降级为拒绝，而非沿用旧价） |
| `DUPLICATE_SEQ` | 重复序号 | 幂等忽略 |
| `OUT_OF_ORDER` | 序号倒退 | 拒绝 |

## 验证方法

```bash
go vet ./...
go test ./... -race -v
```

测试覆盖：
- **并发重算**：3 个组合共享行情库，各 32 个 goroutine 并发 `Compute`，同组合结果完全一致、不同组合结果互不相同（无串扰），`-race` 通过。
- **行情缺失/过期/非法/重复/乱序**：逐场景断言 `RejectError.Reason` 可区分，且拒绝后状态不漂移。
- **增量 vs 全量一致性**：逐条更新（混入重复与乱序）与一次性装载的 VaR/ES 差值在 1e-9 容差内。
- **可复现性**：同一损益序列两次历史模拟结果逐位相等；参数法 99% 分位对标标准正态理论值 2.3263。
- **压力情景**：受压 VaR 相对基准上升，且基础行情不被污染。

所有单测日志均打印**输入快照**（持仓、价格、序号、时间戳）与**判定依据**（期望原因、实际结果、容差），便于审计与复现。
