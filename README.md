# portfolio-risk-engine-go

本地组合风险计量与压力测试引擎：基于本地行情与持仓数据，提供历史模拟与参数法两种口径的 VaR / ES 计量，支持行情增量更新、并发重算与压力情景叠加，并在其上提供**按时间推进的历史回放（replay）与模型回测（backtest）**。

## 模块结构

| 包 | 职责 |
|---|---|
| `market` | 行情类型、线程安全行情库（`Store`）、行情校验与拒绝原因 |
| `portfolio` | 持仓定义、市值估值、权重归一化 |
| `risk` | VaR/ES 计量（历史模拟、参数法）、风险引擎（`Engine`）、压力情景 |
| `backtest` | 时间轴回放、逐时点风险序列、阈值 vs 真实损益回测、多组合并发隔离 |

## 风险模型口径

### 权重与暴露归一化
- 暴露 = 持仓数量 × 最新价格；多头为正、空头为负，方向不丢失。
- 权重按**净市值**归一（权重和为 1）；完全对冲（净市值为 0）时退化为按**总绝对暴露**归一，避免除零。
- 任何持仓标的缺价即返回 `MissingQuoteError`，不静默跳过、不按零计价。

### 历史模拟法（`historical`）
- 组合历史损益序列：`pnl[t] = Σ_s weight[s] × return[s][t] × 组合市值`。
- 损失序列升序排序，VaR 取**最近秩分位**（`k = ceil(c·n)`，无插值歧义）；ES 为不小于 VaR 的损失均值。
- 同一输入结果完全可复现（排序与秩选择均为确定性）。

### 参数法（`parametric`，方差-协方差）
- 假设组合损益正态：`VaR = -(μ - z_c·σ)`，`ES = -(μ - σ·φ(z_c)/(1-c))`。
- 正态逆 CDF 采用 Acklam 有理逼近 + 一步 Halley 精化，确定性实现；标准差计算先排序再累加，稳定浮点求和顺序。

### 压力情景（`stress`）
- 情景定义为 `symbol → 相对冲击`（如 `-0.2` 表示跌 20%）。
- 口径：情景产生一次性损益 `shockPnL = Σ 暴露 × 冲击`，**叠加**到当前组合的历史损益分布上（分布整体平移），再取历史模拟分位。这样冲击不会被归一化权重"洗掉"。
- 情景只作用于本次计算，**不写回行情库**；压力后基础重算结果不变（有测试保证）。
- 情景引用未持有的标的即报错。

## 并发与数据更新的一致性规则

1. **快照隔离**：`Compute`/`Stress` 先取行情库快照（`Store.Snapshot` 返回拷贝），整个计量过程只读快照与不可变的收益历史，多个组合并发重算无数据竞争、无结果串扰（`-race` 验证）。
2. **增量即全量**：引擎不在内存中维护增量中间态，每次计量都从当前行情状态全量推导，因此"逐条增量更新后重算"与"一次性全量装载后重算"结论在容差（1e-9，实际为 0）内一致。
3. **序号防重防乱**：每条行情携带单调递增 `Seq`：
   - `Seq == 当前` → `DUPLICATE_SEQ`，幂等忽略，不重复计价；
   - `Seq < 当前` → `OUT_OF_ORDER`，拒绝；
   - 被拒绝的更新不改变已有状态，结论不漂移。
4. **估值时刻**：取快照中最新行情时间作为估值参考时刻，各标的行情相对该时刻做时效校验。

## 异常行情处理策略

所有异常均以 `*market.RejectError` 返回，`Reason` 字段可区分，绝不静默跳过或按零处理：

| 原因 | 触发条件 | 行为 |
|---|---|---|
| `INVALID_PRICE` | 价格 ≤ 0、NaN、±Inf 或空标的 | 写入时拒绝 |
| `MISSING_QUOTE` | 持仓标的无行情 | 计量时失败 |
| `STALE_QUOTE` | 行情时间距估值时刻超过 `maxStaleness` | 计量时失败（降级为拒绝，而非沿用旧价） |
| `DUPLICATE_SEQ` | 重复序号 | 幂等忽略 |
| `OUT_OF_ORDER` | 序号倒退 | 拒绝 |

## 历史回放与模型回测（`backtest`）

### 时间轴与输入口径
- `Dataset` 为按 `AsOf` **严格递增**排列的时点序列；每个 `Step` 包含：
  - `Quotes`：在该时点"送达"的行情（`Price` + 单调 `Seq`），行情时间戳取该时点；
  - `Returns`：**截至该时点已知**的各标的历史收益序列（风险窗口）；
  - `NextReturns`：该时点之后下一期**真实实现**的收益（仅供回测对照）。
- `Run` = 回放 + 回测；`Replay` 只产出风险数值序列、不做真实损益对照。
- 组合暴露口径：`pnl[t] = Σ_s 数量_s × 价格_s[t] × 收益_s[t]`，直接用暴露×收益累加。净市值为 0 的完全对冲组合仍按总绝对暴露保有量纲，不会因净市值除零而得到零风险。

### 不能用到未来数据的约束（no lookahead）
1. 时点 t 的风险阈值**只**由时点 t 及之前已送达的 `Quotes`、以及 `Returns[t]` 中截至 t 已知的窗口决定；`NextReturns` 与后续时点在计量阶段完全不参与。
2. 每个组合持有**独立**行情库与独立累计状态，沿时间轴顺序推进，多组合并发仅用于提速。
3. 可复现性：持仓标的按字典序排序后累加（不依赖 map 遍历顺序），分位采用确定性最近秩；输出按"输入组合顺序 × 口径顺序"排列。同一份数据重跑逐位一致，换机器、换并发执行顺序结果相同。有测试：并发结果 == 逐组合顺序运行结果 == 再跑一遍结果；篡改 `NextReturns`/删除后续时点不改变已有时点阈值。

### 回测统计口径
- 逐点对照：`损失 = -下一期真实组合损益`，当 `损失 > VaR`（严格大于）记为一次突破（breach）。
- 每个 `(组合, 口径)` 单独给出：`Evaluated`（成功对照点数）、`Breaches`、`BreachRate = Breaches/Evaluated`、`WorstLoss`（最差一期损失，无样本为 NaN）、完整风险 `Series`、逐点 `Outcomes`。
- 结论可按**口径**（historical/parametric）与**组合名**分别检索。
- `Healthy` 可信标记：存在任何 `FAILED` 时点，或回测模式下没有一个成功对照点，则 `Healthy=false` —— 个别时点有问题不会被包装成"看似正常"的整体结论。

### 时点状态与可区分原因
绝不静默跳过、不以零顶替。每个时点为以下状态之一，问题进入 `Report.Issues`：

| Reason | 触发条件 | Status |
|---|---|---|
| `WARMUP` | 可见收益样本数 `< MinSamples`（默认 30），尚在预热 | WARMUP（跳过，不计入统计） |
| `NO_REALIZED_PNL` | 缺下一期真实收益（如时间轴末端），无法对照；风险序列仍保留 | SKIPPED（不计入回测统计） |
| `MISSING_QUOTE` | 持仓标的在该时点无任何行情 | FAILED |
| `STALE_QUOTE` | 最近行情距该时点超过 `MaxStaleness`（0 表示关闭时效校验） | FAILED |
| `INVALID_DATA` | 价格 ≤0/NaN/±Inf，或历史/真实收益为 NaN/±Inf、窗口长度不一 | FAILED |
| `DUPLICATE_SEQ` | 重复序号 | 幂等忽略，沿用旧价继续计量 |
| `OUT_OF_ORDER` | 序号倒退 | FAILED（旧价不被覆盖） |
| `MISSING_RETURN` | 该时点缺某持仓标的的历史收益窗口 | FAILED |
| `DEGENERATE_SERIES` | 总绝对暴露为 0，或组合损益序列退化为常数（多空完全相抵、零离散） | FAILED（拒绝零风险假象） |

配置级错误（空数据集、时间轴非严格递增、未知口径、置信度不在 (0,1)、空组合/重名等）在启动阶段直接以 `ConfigError` 拒绝运行，而不是逐点吞没。

### 兼容范围与边界
- 预热时点与末端无真实损益时点不进入 `Evaluated`/突破统计，但保留在轨迹中，可与失败明确区分。
- 个别时点 FAILED **不中断**后续时点回放（每个时点独立判定）；失败记录与原因完整保留，整体 `Healthy=false`。
- 重复序号幂等、乱序序号拒绝，行情库语义与现有 `market.Store` 完全一致。
- 方向接近中性但损益仍有离散的组合，VaR 必须严格为正（有测试保证）。

## 验证方法

```bash
go vet ./...
go test ./... -race -v
```

测试覆盖：
- **并发重算**：3 个组合共享行情库，各 32 个 goroutine 并发 `Compute`，同组合结果完全一致、不同组合结果互不相同（无串扰），`-race` 通过。
- **行情缺失/过期/非法/重复/乱序**：逐场景断言 `RejectError.Reason` 可区分，且拒绝后状态不漂移。
- **增量 vs 全量一致性**：逐条更新（混入重复与乱序）与一次性装载的 VaR/ES 差值在 1e-9 容差内。
- **可复现性**：同一损益序列两次历史模拟结果逐位相等；参数法 99% 分位对标标准正态理论值 2.3263。
- **压力情景**：受压 VaR 相对基准上升，且基础行情不被污染。
- **回放预热不足**：样本不足时点以 `WARMUP` 显式跳过，不进序列/统计。
- **回测突破统计**：逐点对照断言突破次数、突破比例（2/3）与最差一期亏损；末端无真实损益以 `NO_REALIZED_PNL` 跳过。
- **回放行情异常**：缺失 `MISSING_QUOTE`、过期 `STALE_QUOTE`、非法价格/收益 `INVALID_DATA`、序号倒退 `OUT_OF_ORDER`、重复序号幂等，原因彼此可区分；失败使整段结论 `Healthy=false`。
- **多空相抵/近中性**：完全对冲且零离散 → `DEGENERATE_SERIES` 失败；近中性但有离散 → VaR 严格为正，无零风险假象。
- **多组合并发回放**：3 组合 × 2 口径，并发结果与逐组合顺序运行、以及二次重跑逐字段一致；不同组合风险随持仓线性放大、互不雷同，`-race` 通过。
- **禁止偷看未来**：篡改下一期真实收益、删除后续时点后，已有时点风险阈值逐位不变。
- **配置校验**：空数据集、时间轴非严格递增、未知口径、置信度越界在启动阶段拒绝。

所有单测日志均打印**输入快照**（持仓、价格、序号、时间戳、收益窗口、下一期真实收益）与**判定依据**（期望原因、实际结果、容差/期望值），便于审计与复现。
